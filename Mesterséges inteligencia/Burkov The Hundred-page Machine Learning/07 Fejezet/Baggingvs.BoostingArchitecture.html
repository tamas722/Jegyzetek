Bagging vs. Boosting Architecture

Structural difference between Random Forest (Parallel) and Gradient Boosting (Sequential Residual Chain)

3 Trees
Bagging (Random Forest) Parallel

Trees are trained independently in parallel on random bootstrap samples. Final prediction is the simple average of all trees.

Main Goal: Reduces Variance (Prevents Overfitting)
Gradient Boosting Sequential

Trees are trained sequentially. Each new tree fits specifically on the residual error left by the previous trees.

Main Goal: Reduces Bias (Fixes Underfitting)
